TRENDBEACON AUTOMATED PHASES 1-4

PHASE 1: Google Trends UK RSS updates Trending Now and Rising Trends.
PHASE 2: Product-led trends are matched to Amazon UK search links using tradebeacon-21. No PA API data, prices, ratings or availability are claimed.
PHASE 3: Deterministic SEO report pages are generated in /reports from sourced trend fields.
PHASE 4: Opportunity Radar stages use transparent search-volume thresholds stored in trend-data.json.

UPLOAD
1. Extract the ZIP.
2. Upload every file and folder to the GitHub repository root.
3. Preserve .github/workflows/update-trends.yml.
4. Commit.
5. Open Actions > Update TrendBeacon Trends > Run workflow.
6. Refresh GitHub Pages after the workflow succeeds.

The chosen Bloomberg Dark design is retained.
